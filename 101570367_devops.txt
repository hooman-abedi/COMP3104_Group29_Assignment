COMP3104 DevOps introduces the practices and tools teams use to deliver software continuously. DevOps removes the wall between development and operations so that code can move from a developer's computer to production quickly, safely and repeatedly.

Main topics and tools in the course:
- Git version control and commit history
- GitHub repositories, collaborators and pull requests
- Per-developer and per-feature branching strategies
- Merge conflict resolution
- Continuous Integration / Continuous Deployment (CI/CD)
- GitHub Actions workflows written in YAML
